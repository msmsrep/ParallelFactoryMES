製造実行システム（MES）AGPL-3.0.NET 10 / Blazor

製造指図から出荷まで、ロットでつないで記録する。

Parallel Factory MES は、工場の製造実績をブラウザで記録・追跡するオープンソースのMESです。指図・作業・在庫・検査・出荷を一本の流れとして扱い、どの部材ロットからどの製品ロットができたかを、いつでも両方向にたどれます。

ソースコードを見る ユーザーガイドを読む

工場の一日を、ひとつの画面群で

部署ごとに別々の表で管理していた記録を、同じロット番号でつなぎます。前の工程が終わっていなければ次へ進めない、検査が通っていなければ出荷できない――そうした業務の順番をシステムが守ります。

  1. マスタ登録品目・工順・設備
  2. 受入部材ロットを計上
  3. 製造指図登録・承認
  4. 工程展開作業指示と産出ロット
  5. 差立作業者・設備を割当
  6. 段取りチェックリスト
  7. 実績入力良品・不良・投入
  8. 完了承認工程の締め
  9. 検査測定値を自動判定
  10. 出荷判定可・特採・否
  11. 出荷判定済みだけ出せる

指図を登録すれば、
工程ごとの作業指示が並ぶ

製造指図を承認して工程展開すると、品目に登録した工順どおりに作業指示が作られ、産出ロットも自動で採番されます。状態は色で見分けられ、勝手に飛び越すことはできません。

未承認→承認済→展開済→完了

紙の指示書と現品票も、
そのまま印刷して現場へ

作業指示書にはその工程で使う部品と必要数、記録欄、バーコードが入ります。ロットごとの現品票も発行でき、PDFに書き出せます。

  • 読み取りはUSBのバーコードリーダーでも、タブレットのカメラでも
  • ロット番号や作業指示番号の入力欄はすべてスキャンに対応
H-30-10-01-02

この製品には、どのロットが
使われていたか

製品ロットの番号を読み取るだけで、使われた半製品・部材のロットを最後までたどれます（トレースバック）。逆に、ある部材ロットが使われた製品を洗い出すこともできます（トレースフォワード）。

  • ロットごとに、どの作業指示で投入されたかが並ぶ
  • 「このロットを追跡」で次の階層へそのまま移れる
  • 製造・検査・入出庫の履歴も同じ画面で
D-10-30-01D-10-30

在庫は「ロット×場所」で持つ

受入・製造・出荷のたびに在庫が動き、入出庫の履歴が残ります。ロケーション移動、数量調整、分割・統合、保留や廃棄といった操作も、理由とともに記録されます。

  • 有効期限の近いロットを知らせる期限アラート
  • 保留・不適合のロットは出庫や投入で止まる
  • 棚卸、搬送指示、出庫・払出の画面もあり
B-60-10-05C-40-10-03

数字は「製造日」で締める

直行率・歩留まり・不良率を、品目別・工程別・直別に集計します。夜勤が日付をまたいでも、境界時刻（既定は朝6時）までの実績は同じ製造日にまとまります。

9月21日の製造日
21日 6:0012:0018:000:0022日 6:00
斜線は21時からの夜勤。日付が変わっても、翌朝6時までの実績は21日の製造日に入ります。境界時刻は設定で変えられます。
監査ログ

誰が・いつ・何を変えたか

実績の訂正、検査結果の訂正、マスタの変更、在庫操作、取消。記録を変える操作はすべて監査ログに残り、訂正なら変更前と変更後も保存されます。

  • ログ自体は書き換えも削除もできない
  • 保持期間を過ぎた分の整理も、整理したこと自体が記録に残る
  • 権限はロールごと。参照は開いたまま、書き込みの操作だけを絞る
CSVZIP

立ち上げは、CSVをまとめて

品目・工順・設備・検査項目などのマスタは、CSVで一括登録・出力できます。ZIPにまとめれば一度に取り込めて、1行でもエラーがあれば全件取り消し。先に「検証のみ」で確かめられます。

  • UTF-8 と Shift_JIS を自動判別
  • 受入・実績・検査などの実績もCSVで取り込める（試験・移行・教育用）
  • そのまま取り込めるサンプルデータ一式つき。このページの画面もそれで作りました

動かしてみる

  1. 起動する

    リポジトリのルートで実行します。データベース（SQLite）は自動で作られます。

    dotnet run --project src/MesApp.Api
  2. 管理者を作る

    ブラウザで http://localhost:5288 を開くと、初期セットアップの案内が出ます。

  3. サンプルを入れる

    samples/master-csv と samples/actual-csv をそれぞれZIPにして取り込むと、製造指図から出荷まで試せる状態になります。

使いかた

社内LANのサーバーで

1台で起動し、現場のPCやタブレットはブラウザで開くだけ。端末へのインストールもライセンス認証も要りません。

試すだけなら、1台のPCで テスト・検証用

API・データベース・画面をひとつにまとめたWindowsデスクトップ版もあります。サーバーもネット接続も要らないので、機能を試したり検証したりするのに向いています。現場での本番運用は、上のサーバー構成でお使いください。

いまできること・まだのこと

利用できます

  • 生産管理製造指図・工程展開・進捗・差立
  • 製造実行段取り・チェックリスト・実績・作業時間・トラブル報告
  • 物流・在庫受入・在庫操作・出庫／払出・出荷・棚卸・搬送指示
  • 品質検査指示・実績・判定・不適合・品質分析
  • 品質保証出荷判定・トレーサビリティ
  • 設備保全稼働記録・保全計画／指示／実績・手順書・治工具寿命
  • 帳票指示書・現品票などの印刷、バーコード／QR読み取り

まだ使えません

  • PostgreSQL / SQL Server への接続（現在は SQLite のみ）
  • シート・端末のライセンス管理
  • Docker での配布
  • HTTPS の終端（LANではリバースプロキシで）
