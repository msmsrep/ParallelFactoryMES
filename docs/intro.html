製造実行システム（MES）AGPL-3.0.NET 10 / Blazor

製造指図から出荷まで、ロットでつないで記録する。

Parallel Factory MES は、工場の製造実績をブラウザで記録・追跡するオープンソースのMESです。指図・作業・在庫・検査・出荷を一本の流れとして扱い、どの部材ロットからどの製品ロットができたかを、いつでも両方向にたどれます。

ユーザーガイドを読む 入手する

工場の一日を、ひとつの画面群で

部署ごとに別々の表で管理していた記録を、同じロット番号でつなぎます。前の工程が終わっていなければ次へ進めない、検査が通っていなければ出荷できない――そうした業務の順番をシステムが守ります。

  1. マスタ登録品目・工順・設備
  2. 受入部材ロットを計上
  3. 製造指図登録・承認
  4. 工程展開作業指示と産出ロット
  5. 差立作業者・設備を割当
  6. 段取りチェックリスト
  7. 実績入力良品・不良・投入
  8. 完了承認工程の締め
  9. 検査測定値を自動判定
  10. 出荷判定可・特採・否
  11. 出荷判定済みだけ出せる

指図を登録すれば、
工程ごとの作業指示が並ぶ

製造指図を承認して工程展開すると、品目に登録した工順どおりに作業指示が作られ、産出ロットも自動で採番されます。状態は色で見分けられ、勝手に飛び越すことはできません。

未承認→承認済→展開済→完了
バーコードQR

紙の指示書と現品票も、
そのまま印刷して現場へ

作業指示書にはその工程で使う部品と必要数、記録欄、バーコードが入ります。ロットごとの現品票も発行でき、PDFに書き出せます。

  • 読み取りはUSBのバーコードリーダーでも、タブレットのカメラでも
  • ロット番号や作業指示番号の入力欄はすべてスキャンに対応
H-30-10-01-02

この製品には、どのロットが
使われていたか

製品ロットの番号を読み取るだけで、使われた半製品・部材のロットを最後までたどれます（トレースバック）。逆に、ある部材ロットが使われた製品を洗い出すこともできます（トレースフォワード）。

  • ロットごとに、どの作業指示で投入されたかが並ぶ
  • 「このロットを追跡」で次の階層へそのまま移れる
  • 製造・検査・入出庫の履歴も同じ画面で
D-10-30-01D-10-30

在庫は「ロット×場所」で持つ

受入・製造・出荷のたびに在庫が動き、入出庫の履歴が残ります。ロケーション移動、数量調整、分割・統合、保留や廃棄といった操作も、理由とともに記録されます。

  • 有効期限の近いロットを知らせる期限アラート
  • 保留・不適合のロットは出庫や投入で止まる
  • 棚卸、搬送指示、出庫・払出の画面もあり
B-60-10-05C-40-10-03

数字は「製造日」で締める

直行率・歩留まり・不良率を、品目別・工程別・直別に集計します。夜勤が日付をまたいでも、境界時刻（既定は朝6時）までの実績は同じ製造日にまとまります。

9月21日の製造日
21日 6:0012:0018:000:0022日 6:00
斜線は21時からの夜勤。日付が変わっても、翌朝6時までの実績は21日の製造日に入ります。境界時刻は設定で変えられます。
監査ログ

誰が・いつ・何を変えたか

実績の訂正、検査結果の訂正、マスタの変更、在庫操作、取消。記録を変える操作はすべて監査ログに残り、訂正なら変更前と変更後も保存されます。

  • ログ自体は書き換えも削除もできない
  • 保持期間を過ぎた分の整理も、整理したこと自体が記録に残る
  • 権限はロールごと。参照は開いたまま、書き込みの操作だけを絞る
CSVZIP

立ち上げは、CSVをまとめて

品目・工順・設備・検査項目などのマスタは、CSVで一括登録・出力できます。ZIPにまとめれば一度に取り込めて、1行でもエラーがあれば全件取り消し。先に「検証のみ」で確かめられます。

  • UTF-8 と Shift_JIS を自動判別
  • 受入・実績・検査などの実績もCSVで取り込める（試験・移行・教育用）
  • そのまま取り込めるサンプルデータ一式つき。このページの画面もそれで作りました

入手する

どれも無償で、ライセンス認証もありません。ZIP・Docker・ストア版は .NET のインストールも不要です。

1台で試す

Microsoft Store

API・データベース・画面をひとつにまとめた Windows のデスクトップ版です。サーバーもネット接続も要らないので、機能を試したり検証したりするのに向いています。

Microsoft Store で入手 Windows 10（2004 以降）/ 11
社内サーバー

ZIP

展開して start.cmd（Linux は sh start.sh）を実行するだけ。ランタイム同梱の自己完結版です。

Releases からダウンロード Windows / Linux（x64）・ポート 5000
社内サーバー

Docker

データはボリュームに残ります。PostgreSQL と一緒に動かすなら compose.postgres.yaml を使います。

docker run -d -p 8080:8080 \
  -v mesapp-data:/data \
  ghcr.io/msmsrep/parallelfactorymes
amd64 / arm64・ポート 8080

動かしてみる

  1. 起動する

    上のどれかで起動し、ブラウザで http://localhost:5000（Docker は 8080）を開きます。ストア版はアプリの画面がそのまま開きます。データベース（SQLite）は自動で作られます。

  2. 管理者を作る

    最初は初期セットアップの案内が出るので、管理者を作ります。ストア版は管理者が自動で作られ、ユーザー名と初期パスワードが画面の上に表示されます。

  3. サンプルを入れる

    マスタ・実績のサンプルZIPをこの順に取り込むと、製造指図から出荷まで試せる状態になります。

使いかた

社内LANのサーバーで

ZIP か Docker で1台に置き、現場のPCやタブレットはブラウザで開くだけ。端末へのインストールもライセンス認証も要りません。本番運用はこちらの構成でお使いください。

試すだけなら、1台のPCで テスト・検証用

Microsoft Store のデスクトップ版は、ほかの端末からは接続できません。機能を試したり、手順を検証したりするのに使います。
