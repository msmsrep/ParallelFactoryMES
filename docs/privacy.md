## 要約

- **本アプリは、利用者のデータを開発者や第三者に送信しません。**
- Microsoft Store 版では、データはすべて**お使いのPC内**に保存されます。
- 利用状況の収集（テレメトリ・アクセス解析・広告）は**一切行いません**。
- 外部のサーバーやクラウドサービスへの接続を必要としません。

## 1. 本アプリが保存するデータ

本アプリは製造実行システム（MES）であり、業務上の記録を保存します。保存されるのは、利用者が画面から入力した内容と、その操作の記録です。

| 種別 | 内容 |
|---|---|
| 利用者情報 | ユーザー名、表示名、所属部署、所属作業区・直、ロール（権限）、パスワード（**ハッシュ化して保存**し、元のパスワードは保持しません） |
| 業務データ | マスタ（品目・工程・設備・取引先など）、製造指図、作業指示、作業実績、在庫、検査記録、出荷記録、保全記録など |
| 操作履歴（監査ログ） | 操作日時、操作したユーザー名、操作の種類と対象、変更内容、接続元IPアドレス |

作業実績や監査ログには、**誰がいつ操作したか**が記録されます。製造記録の追跡可能性を確保するための機能であり、この記録も他の業務データと同じくPC内（またはご利用の組織のサーバー内）に留まります。

## 2. データの保存場所

### Microsoft Store 版（デスクトップアプリ）

[Microsoft Store](https://apps.microsoft.com/detail/9p9fqjzh23hc?hl=ja-JP&gl=JP) から入手するデスクトップアプリです。

データベース、認証用の署名鍵、起動ログ、WebView2 のユーザーデータは、Windows がこのアプリ専用に割り当てる領域に保存されます。

```
%LOCALAPPDATA%\Packages\msmsrep.ParallelFactoryMES_77t1an0ygyrva\LocalState
```

本アプリはアプリケーションサーバーを**PC内部（ループバックアドレス `127.0.0.1`）でのみ**起動します。この通信はPCの外に出ず、同じネットワーク上の他の機器からも接続できません。

**アプリをアンインストールすると、上記フォルダーごとデータは削除されます。** 残したいデータがある場合は、アンインストール前にバックアップ（[管理者向け運用](operations.html)を参照）を取得してください。

### サーバーに配置して使う場合

データの保存場所は、配置した組織のサーバーおよびデータベースです。その管理・保護は配置した組織の責任範囲となります。本アプリの開発者はそのデータにアクセスできません。

## 3. 第三者への提供・外部送信

本アプリは、保存したデータを開発者を含むいかなる第三者にも送信・提供しません。データの外部送信が発生するのは、利用者自身が次の操作を行った場合に限られ、いずれも送信先は利用者が指定します。

- CSV ファイルの出力、帳票・ラベルの印刷
- データベースファイルのバックアップ（利用者が指定した場所への保存）

## 4. Microsoft Edge WebView2 について

本アプリは画面表示に Microsoft Edge WebView2 ランタイム（Microsoft Corporation 提供）を使用します。本アプリは WebView2 で外部のWebサイトを読み込みません（表示するのは前項のループバックアドレスのみ）。WebView2 ランタイム自体の更新や、そのコンポーネントが行う通信は Microsoft の管理下にあり、[Microsoft のプライバシーに関する声明](https://privacy.microsoft.com/ja-jp/privacystatement)が適用されます。

## 5. 利用者の権利

データはすべて利用者の管理下にあります。

- **閲覧・訂正**：画面から確認・修正できます。訂正の履歴は監査ログに残ります。
- **削除**：アプリのアンインストールで、保存されたデータはすべて削除されます。監査ログのみを期間指定で削除することもできます（システム管理者権限が必要）。
- 開発者に対する削除・開示の請求は不要です。開発者はデータを保持していません。

## 6. 子どものプライバシー

本アプリは事業者向けの業務用ソフトウェアであり、子どもを対象としていません。年齢に関する情報を収集することもありません。
