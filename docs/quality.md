検査の発行・入力・判定・承認、不適合の対応指示・承認ができるのは
**システム管理者・品質管理担当者** です。不適合の起票と対応実績の記録は全ユーザーが行えます。

---

## 検査管理

**左メニュー：品質 → 検査管理**

### 検査指示を発行する  {#issue-inspection}

<ol class="steps">
<li><strong>検査種別</strong>を選びます。受入検査／工程内検査／完成品検査／サンプル検査／再検査 の5種類です。</li>
<li>工程内検査の場合は<strong>対象作業指示</strong>を選びます。それ以外は<strong>対象ロット</strong>を指定します（スキャンまたはプルダウン）。</li>
<li>必要なら<strong>備考</strong>を入力し、<strong>検査指示を発行</strong>を押します。</li>
</ol>

発行すると検査指示番号が採番され（`IN20260501-0001`）、**対象ロットの在庫ステータスが「検査待ち」になります**。

<div class="note">
<p><strong>検査項目は自動で選ばれます。</strong> マスタ管理 → 検査項目・基準 に登録された項目のうち、
検査種別・対象品目・対象工程が合致するものが検査指示に組み込まれます。
該当する基準がないと次のエラーになります。</p>
<p><code>対象に合致する検査基準がありません。検査項目マスタを登録するか itemIds を指定してください。</code></p>
</div>

### 検査進捗を確認する

一覧では状態別に絞り込めます。

| 状態 | 意味 |
|---|---|
| 指示 | 発行済み、実績未入力 |
| 実施中 | 一部の項目に実績が入っている |
| 判定済 | 総合判定が確定した（合格／不合格） |
| 承認済 | 承認され確定した |
| 取消 | 取り消された |

「判定」列には、合格は緑、不合格は赤のバッジが表示されます。

## 検査実績の入力と判定

一覧の **詳細・実績入力** ボタンから、検査指示の詳細を開きます。

### 検査実績を入力する

検査項目ごとに、規格値（下限〜上限）と検査方法が表示されます。

<ol class="steps">
<li><strong>測定値</strong>を入力します。規格値の範囲と照合して、合否が<strong>自動判定</strong>されます。</li>
<li>数値でない検査は<strong>定性記録</strong>に文字で記入します。</li>
<li>自動判定できない項目（規格値が未設定の項目）は、<strong>判定（手動）</strong>で合格／不合格を選びます。</li>
<li><strong>検査実績を登録</strong>を押します。</li>
</ol>

入力した項目だけが登録されます。何度かに分けて入力しても構いません。

<div class="warn">
<p>規格値が設定されていない項目に測定値だけを入れると、次のエラーになります。
<code>検査項目 '○○' は規格値による自動判定ができません。judgmentを指定してください。</code>
その項目の「判定（手動）」で合格／不合格を選んでください。</p>
</div>

### 総合判定する

**全検査項目の実績を登録してから** 判定します。

<ol class="steps">
<li>必要なら<strong>グレード</strong>を入力します（検査結果で出荷先や等級が変わる製品向け。任意）。</li>
<li><strong>判定する</strong>を押します。</li>
</ol>

判定のルールと結果は次のとおりです。

| 結果 | 条件 | 対象ロットへの反映 |
|---|---|---|
| 合格 | すべての検査項目が合格 | 在庫ステータスが **正常** になります |
| 不合格 | 1項目でも不合格がある | 在庫ステータスが **不良** になり、**不適合が自動で起票されます** |

実績が未登録の項目が残っていると判定できません。

> `実績未登録の検査項目が N 件あります。全項目の実績登録後に判定してください。`

### 承認する

判定済みになると **検査承認** ボタンが表示されます。押すと状態が「承認済」になり確定します。

### 検査成績書の発行

画面上部の **検査成績書** ボタンで印刷ページが開きます。

### 検査指示を取消す  {#inspection-cancel}

誤って発行した検査指示は **検査指示を取消** で取り消せます（承認済み・取消済みは不可）。

<div class="note">
<p>取消すと、その指示のために<strong>検査待ちで拘束していたロットが解放され、正常に戻ります</strong>。
判定が済んでいる指示を取り消しても、ロットの現在のステータスはそのままです。</p>
</div>

### 検査実績を訂正する

実績一覧の各行にある **訂正** から修正できます。

<ol class="steps">
<li>正しい<strong>測定値</strong>と<strong>判定</strong>を入力します。</li>
<li><strong>訂正理由</strong>を入力します（<strong>必須</strong>）。</li>
<li><strong>訂正を登録</strong>を押します。</li>
</ol>

訂正内容と理由は監査ログに記録されます。

<div class="warn">
<p><strong>承認済みの検査は訂正できません。</strong> また、判定済みの検査を訂正した場合は、
もう一度<strong>総合判定をやり直す</strong>必要があります。</p>
</div>

## 不適合管理

**左メニュー：品質 → 不適合管理**

検査不合格による自動起票のほか、現場で見つかった逸脱・不具合を手動で起票できます。

### 不適合を起票する

<ol class="steps">
<li><strong>発生元</strong>を選びます。生産実績／検査／受入 のいずれかです。</li>
<li>関連する<strong>対象ロット</strong>や<strong>対象作業指示</strong>を選びます（任意）。</li>
<li><strong>原因区分</strong>を入力します（例：設備不調／作業ミス／部材不良）。品質分析の集計軸になります。</li>
<li><strong>内容</strong>と<strong>原因詳細</strong>を記入し、<strong>不適合を起票</strong>を押します。</li>
</ol>

不適合番号が採番されます（`NC20260501-0001`）。

<div class="note">
<p><strong>原因区分は自由入力です。</strong> 表記がばらつくと品質分析の集計が分散するため、
工場内で使う語を決めておくことをおすすめします。</p>
</div>

### 不適合の対応を指示する  {#nc-action}

一覧の各不適合カードで、対応区分を選んで指示します（品質管理担当者）。

| 対応区分 | 実行される処理 |
|---|---|
| リワーク | **リワーク指図が自動作成されます** |
| 保留 | 対象ロットの在庫ステータスが「保留」になります |
| 廃棄 | 対象ロットの在庫ステータスが「廃棄予定」になります |
| 特別採用 | 承認時にロットが解放されます |

対応区分と指示内容を入力して **対応指示** を押すと、状態が「対応指示済」になります。
作成されたリワーク指図の番号は、不適合カードにバッジで表示されます。

### 対応実績を記録する

対応が終わったら、「対応実績」欄に内容を入力して **対応記録** を押します。状態が「対応完了」になります。

### 承認（クローズ）する

**承認（特採時はロット解放）** を押すと、不適合がクローズされます。
対応区分が「特別採用」の場合、このタイミングで対象ロットの在庫ステータスが正常に戻ります。

対応指示を出す前の不適合は承認できません。

## 品質分析

**左メニュー：品質 → 品質分析**

期間を指定して集計します。**期間は製造日（業務日付）基準**です。

| セクション | 内容 |
|---|---|
| サマリ | 検査の合格件数／不合格件数、未クローズの不適合件数 |
| 品目別の不良集計 | 品目ごとの良品数・不良数・不良率 |
| 工程別の不良集計 | 工程ごとの良品数・不良数・不良率 |
| 不適合の原因区分別 発生件数 | 起票時に入力した原因区分ごとの件数 |

開始日・終了日を入れて **集計** を押すと再計算されます。日付を空欄にすると全期間が対象です。
未クローズの不適合がある場合は「要対応」バッジが表示されます。
