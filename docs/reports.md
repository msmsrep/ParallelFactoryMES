## 印刷できる帳票

帳票ボタンを押すと印刷用ページが**別タブ**で開きます。
ページ上部の印刷ボタン、またはブラウザの印刷機能（Ctrl+P）から印刷またはPDF保存してください。

| 帳票 | どこから出すか | 内容 |
|---|---|---|
| 作業指示書 | 作業指示 一覧／製造指図 詳細 の **指示書** | 指示番号・指図番号・品目・工程・計画数・担当者・設備・構成部品（MBOM） |
| 現品票（ラベル） | 受入／在庫照会／トレーサビリティ の **現品票** | 品目・数量・製造日／受入日・有効期限・ステータス・グレードと、**ロット番号のバーコード** |
| 検査成績書 | 検査詳細の **検査成績書** | 検査項目ごとの規格値・測定値・判定 |
| 出荷伝票 | 出荷管理の **出荷伝票** | 出荷先・予定日・明細 |
| 出荷判定書 | 出荷判定の **判定書** | 判定結果・判定者・判定日 |
| 棚卸表 | 棚卸の **棚卸表** | 棚卸対象の明細（実棚記入用） |

<div class="note">
<p>PDFで残したい場合は、印刷ダイアログでプリンタに「PDFとして保存」（Microsoft Print to PDF など）を選んでください。</p>
</div>

## バーコード／QRの運用

### 現品票のバーコード

現品票にはロット番号が **Code39** のバーコードで印刷されます。
受入時や製造完了時に現品票を印刷して現物に貼っておくと、以降の作業をスキャンで進められます。

### スキャンが使える場面

| 画面 | 使いどころ |
|---|---|
| 受入 | 納入元のロット番号をそのまま登録する |
| 在庫照会 | ロット番号で在庫を検索する |
| 出庫・払出 | ピッキング時に、引当ロットと現物ラベルを照合する |
| 検査管理 | 検査対象のロットを指定する |
| トレーサビリティ | 追跡するロットを指定する |

### 読み取りの方法

| 方法 | 準備 | 使いかた |
|---|---|---|
| USBバーコードリーダー | 端末にUSB接続するだけ（キーボードとして認識されます） | 入力欄をクリックしてから読み取ります。リーダーが送るEnterで確定します |
| 端末のカメラ | HTTPS接続が必要 | **📷 カメラ** を押し、コードを映します。読み取ると自動入力され、カメラは停止します |
| 手入力 | 不要 | 直接キーボードで入力します |

<div class="warn">
<p><strong>カメラでの読み取りは、HTTPS接続か <code>localhost</code> でのみ動作します。</strong>
ブラウザのセキュリティ制約によるもので、システム側では回避できません。</p>
<p>HTTPでLAN運用している場合は、<strong>USBバーコードリーダーの利用を推奨します</strong>。
カメラを使いたい場合は、リバースプロキシ（IIS / nginx）でHTTPS化してください
（<a href="operations.html">管理者向け運用</a>）。</p>
</div>

カメラが使えない環境では、次のメッセージが表示されます。

> カメラを利用できません（未対応ブラウザ／権限拒否）。USBバーコードリーダーまたは手入力をご利用ください。

ブラウザがカメラの利用許可を求めてきた場合は「許可」を選んでください。
一度拒否した場合は、ブラウザのアドレスバーのアイコンから権限を変更できます。

## 現場運用のヒント

- **受入したらすぐ現品票を印刷して貼る。** 以降のピッキング照合・検査・トレースがすべてスキャンで進みます。
- **ピッキングは必ず照合してから実行する。** 一致／不一致の表示は目視確認用で、不一致でも実行ボタンは押せてしまいます。
- **作業指示書を工程に配る。** 構成部品（MBOM）が載っているので、部材の取り違え防止になります。
