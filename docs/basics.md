## 画面の構成

ログイン後の画面は、左のメニューと右の作業エリアで構成されています。

### 左メニュー

| グループ | メニュー | 内容 |
|---|---|---|
| — | ダッシュボード | 日次・週次・月次の実績KPI（不良率・稼働率）の推移と工程・品目・直・ライン・設備別の内訳、製造指図の工程進捗 |
| 生産・製造実行 | 製造指図 | 指図の登録・承認・工程展開 |
| | 差立 | 作業指示への作業者・設備・着手順の割当 |
| | 作業指示 | 作業指示の一覧、段取り・実績入力への入口 |
| | 工程進捗・トラブル | 工程別の進捗集計、トラブル報告と対応履歴 |
| 物流・在庫 | 受入 | 部材の受入登録、現品票印刷 |
| | 在庫照会・操作 | 在庫の検索、移動・調整・分割・廃棄など |
| | 出庫・払出 | ピッキング指示の作成と実行 |
| | 出荷管理 | 出荷指示・出荷実行・出荷伝票 |
| | 棚卸 | 棚卸指示、実棚入力、差異調整 |
| 品質 | 検査管理 | 検査指示の発行、実績入力、判定、承認 |
| | 不適合管理 | 逸脱・不具合の起票と対応 |
| | 品質分析 | 不良率・不適合の集計 |
| | 出荷判定 | 出荷可否の判定と承認 |
| | トレーサビリティ | ロットの追跡 |
| 設備・保全 | 設備保全 | 稼働記録、保全計画・指示・実績、手順書 |
| | 治工具管理 | 利用実績と寿命管理 |
| 管理 | マスタ管理 | 各種マスタの登録・編集 |

メニュー項目はロールに関係なく全員に表示されます。ただし、**権限のない操作は
登録・承認などのボタンやフォーム自体が表示されません**（一覧の閲覧はできます）。

## 共通の操作

### 一覧のしぼり込み

多くの一覧画面には、上部に状態のプルダウンがあります。選ぶと即座に絞り込まれます。
「全状態」を選ぶと解除されます。

### メッセージの表示

- 緑色の帯：操作が成功したときのメッセージ
- 赤色の帯：エラー内容。処理は実行されていません

エラー文はサーバーからの理由がそのまま表示されます。文言と対処は[困ったときは](troubleshooting.html)にまとめています。

### 状態バッジ

一覧の「状態」列は色付きのバッジで表示されます。

| 色 | 意味の例 |
|---|---|
| 青（情報） | 進行中・指示中 |
| 黄（注意） | 判定済・要対応 |
| 緑（完了） | 承認済・完了・合格 |
| 赤（警告） | 取消・不合格・期限切れ・納期超過 |

各業務のステータス一覧は[リファレンス](reference.html)にまとめています。

### タブ

在庫照会・設備保全・マスタ管理・トレーサビリティの各画面は、上部のタブで内容が切り替わります。
タブを切り替えるとその都度データを読み込み直します。

## バーコード／QRの読み取り

入力欄の右に **📷 カメラ** ボタンがある項目は、スキャン入力に対応しています。

| 方法 | 使いかた |
|---|---|
| USBバーコードリーダー | 入力欄をクリックしてから読み取ります。リーダーが送るEnterで確定します |
| カメラ | **📷 カメラ** を押すと映像が表示され、コードを写すと自動で入力されます。**停止**で終了します |
| 手入力 | そのままキーボードで入力できます |

<div class="warn">
<p><strong>カメラ読み取りはHTTPS接続でのみ動作します</strong>（<code>localhost</code> は例外）。
ブラウザの制約によるものです。HTTPで運用している場合は、USBリーダーまたは手入力をご利用ください。
カメラが使えない環境では「カメラを利用できません」と表示されます。</p>
</div>

スキャン入力に対応しているのは、受入のロット番号、在庫照会のロット検索、
ピッキングの照合、検査指示の対象ロット、トレーサビリティのロット番号です。

## 帳票の印刷

一覧の「現品票」「指示書」「検査成績書」などのボタンを押すと、印刷用ページが**別タブ**で開きます。
ページ上部の印刷ボタン、またはブラウザの印刷機能（Ctrl+P）から、印刷またはPDF保存ができます。
詳しくは[帳票・ラベル・スキャン](reports.html)を参照してください。

## 日付の扱い（業務日付）

ダッシュボードの集計や品質分析の期間、各種番号の採番日は、暦日ではなく **業務日付（製造日）** で扱われます。
既定では **午前6時** が日付の境界です。

つまり、5月2日の午前3時に登録した実績は「5月1日」の製造日として集計されます。
夜勤の日跨ぎ実績を同じ製造日にまとめるための仕組みです。境界時刻は設定で変更できます
（[管理者向け運用](operations.html)）。
