## 出荷判定

**左メニュー：品質 → 出荷判定**

<div class="warn">
<p><strong>出荷実行には、その出荷指示に対する承認済みの出荷判定が必須です。</strong>
判定結果が「可」または「特別採用」で、かつ<strong>承認済み</strong>である必要があります。
「保留」のままでは出荷できません。</p>
</div>

判定の登録と承認ができるのは **システム管理者・品質保証担当者** です。

### 判定を登録する

<ol class="steps">
<li><strong>対象出荷指示</strong>を選びます。出荷のゲートとして使う場合は必ず指定してください。</li>
<li>必要に応じて<strong>対象ロット</strong>を選びます。</li>
<li><strong>判定</strong>を選びます。可／保留／特別採用 のいずれかです。</li>
<li><strong>備考</strong>を入力し、<strong>判定を登録</strong>を押します。</li>
</ol>

判定書番号が採番されます（`SJ20260501-0001`）。対象出荷指示と対象ロットの
少なくとも一方を指定する必要があります。

| 判定 | 意味 |
|---|---|
| 可 | 通常どおり出荷してよい |
| 保留 | 出荷を止める。この判定では出荷できません |
| 特別採用（特採） | 規格を外れているが、条件付きで出荷を認める |

### 判定を承認する

一覧の **承認** ボタンを押すと、承認日時が記録され「承認済」になります。
**承認して初めて出荷実行が可能になります。**

### 判定書を発行する

各行の **判定書** ボタンから出荷判定書を印刷できます。

## トレーサビリティ

**左メニュー：品質 → トレーサビリティ**

ロット番号から、そのロットの来歴と行き先をたどります。

### ロットを検索する

上部の入力欄にロット番号を入れて **追跡** を押します。バーコード／QRのスキャンにも対応しています。

在庫照会画面や期限アラートの **追跡** ボタンから来た場合は、自動で検索済みの状態で開きます。

<div class="note">
<p><strong>在庫が0になったロットも追跡できます。</strong> 出荷済み・消費済みのロットもそのまま検索してください。</p>
</div>

検索すると、ロットの基本情報が表示されます。

| 項目 | 内容 |
|---|---|
| ロット番号 / 品目 | 対象の識別情報 |
| 在庫ステータス | 正常／保留／検査待ち／不良／廃棄予定 |
| 由来 | 生産（工程で作られた）／受入（購入した） |
| 製造日・受入日 / 有効期限 | 日付情報 |
| グレード | 検査判定時に設定された等級 |
| 現品票 | クリックで現品票を印刷 |

### 3つのタブで追跡する

#### トレースバック

**このロットを作るために使われた部材ロット**をさかのぼって表示します。
不具合品の原因となった部材を特定するときに使います。ツリー状に、さらに上流の部材まで展開されます。

投入部材の記録がない場合（バックフラッシュもピッキングも行っていない場合）は
「投入部材の記録はありません」と表示されます。

#### トレースフォワード

**このロットが使われた先**を表示します。問題のある部材ロットが、
どの製品ロットに使われたかを特定するときに使います。

#### 履歴

3種類の履歴をまとめて表示します。

- **製造履歴**：どの作業指示・工程で、いつ・誰が作ったか
- **検査履歴**：どの検査指示で、どんな判定を受けたか
- **在庫履歴**：受入・移動・調整・出荷などの在庫トランザクション

### 問題が見つかったときの対応

トレースで対象ロットを特定したら、次の画面で対応します。

| やりたいこと | 操作する画面 |
|---|---|
| 出荷や使用を止める | [在庫照会・操作](logistics.html#stock-ops) → ステータス変更で「保留」 |
| もう一度検査する | [検査管理](quality.html#issue-inspection) → 検査種別「再検査」で指示発行 |
| 作り直す | [不適合管理](quality.html#nc-action) → 対応指示「リワーク」（リワーク指図が自動作成されます） |
| 廃棄する | [在庫照会・操作](logistics.html#stock-ops) → 廃棄 |
