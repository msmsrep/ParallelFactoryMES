## ダッシュボード

**左メニュー：ダッシュボード**

ログイン直後に表示される画面です。上のタブで3つの見方を切り替えます。

| タブ | 内容 |
|---|---|
| サマリ | 選んだ期間の良品数・不良数・不良率・設備稼働率・検査の合否・未クローズの不適合と、製造指図の進捗一覧 |
| 推移（日・週・月） | 日次は14日、週次は12週、月次は12か月ぶんの良品数・不良数（棒）と不良率（点）、稼働率の表。工程・品目・作業区で絞り込めます |
| 内訳（工程・品目・直・ライン・設備） | 選んだ期間の実績を、工程別・品目別・直別・ライン別・作業区別・設備別に分けた表 |

期間は **日次・週次・月次** を選び、**◀ 前へ／次へ ▶** で移動します（日付欄で基準日を直接選ぶこともできます。**今日** で戻ります）。

- 「今日」や日付の区切りは暦日ではなく **製造日** です（既定は朝6時で日付が変わります）。夜勤の実績は、開始した製造日に入ります。
- 週は **月曜始まり** です。
- **稼働率は工程・品目では分けられません**。設備の稼働記録は作業指示との紐付けが任意のためです。稼働率はライン・作業区・設備別で見てください。工程・品目で絞り込んだ推移では稼働率の列が消えます。
- 反対に、**設備別では生産数・不良率を出しません**（設備は作業指示ごとに固定されていないため）。

サマリの進捗一覧は期間に関係なく、今の状態を表示します。

| 列 | 内容 |
|---|---|
| 指図番号 | クリックすると指図詳細に移動します |
| 品目 / 数量 | 対象と計画数 |
| 納期 | 期日を過ぎている指図には **納期超過** の赤いバッジが付きます |
| 状態 | 未承認／承認済／展開済／完了／取消 |
| 工程進捗 | 「2 / 5 工程完了」のように、完了した作業指示の数を表示します |

取消の指図はここには表示されません。全件を見るには製造指図画面を開きます。

## 生産計画と予実  {#plan}

**左メニュー：生産・製造実行 → 生産計画・予実**

**製造日×品目×工程**ごとの計画数量を登録し、工程ごとの出来高（良品数）と突き合わせて達成率を見る画面です。
上のタブで **計画登録** と **予実** を切り替えます。

<div class="note">
<p><strong>MESは計画を立てません。</strong>生産スケジューラーやExcelなど、外で立てた計画を受け取る入れ物です。
計画は製造指図とは結び付かず、登録しても指図・作業指示・実績は変わりません。
指図の数量や納期とは別に、「この日にこの工程で何個作る予定か」を持ちます。</p>
</div>

### 計画を登録する

登録フォームは **システム管理者・生産管理担当者** にのみ表示されます。

<ol class="steps">
<li><strong>製造日</strong>を選びます（初期値は今日の製造日）。</li>
<li><strong>品目</strong>と<strong>工程</strong>を選びます。</li>
<li>必要なら<strong>作業区</strong>を選びます（任意。工場・ライン・エリア・作業区のどの段でも選べます）。</li>
<li><strong>計画数量</strong>と<strong>備考</strong>を入力し、<strong>登録</strong>を押します。</li>
</ol>

- **計画数量 0 は「計画上の休止」**です（休日・計画停止など）。予実では達成率を出しません。
- **同じ製造日・品目・工程・作業区の計画は2つ登録できません。** 数量を直すときは一覧の **編集** から変更します。
  作業区を空欄にした計画も1つの組み合わせとして扱います。
- **同じ製造日・品目・工程で、作業区の範囲が重なる計画は併存できません。**
  たとえば「作業区なし」と「作業区 WC-MC1」、「加工ライン」と「その配下の WC-MC1」は同時に持てません
  （予実で合算するため、全体の計画と内訳の計画が並ぶと二重に数えてしまいます）。
  別々の作業区どうし（WC-MC1 と WC-MC2 など）なら並べられます。
- 不要になった計画は **削除** できます（無効化ではなく削除です）。

一覧は製造日の期間（初期値は今日から7日間）・品目・工程・作業区で絞り込めます。
作業区で絞ると、配下の作業区の計画も表示されます。

### CSVでまとめて登録・出力する

計画登録タブの **CSV入出力** から、計画をCSVでまとめて取り込み・出力できます。
外のスケジューラーやExcelで作った計画を毎日・毎週入れ直す使い方を想定しています。

| 列 | 必須 | 内容 |
|---|:-:|---|
| `BusinessDate` | ○ | 製造日（`yyyy-MM-dd`） |
| `ProductCode` | ○ | 品目コード |
| `ProcessCode` | ○ | 工程コード |
| `WorkCenterCode` | | 作業区コード（段は問わない）。空欄も1つのキーとして扱います |
| `PlannedQuantity` | ○ | 計画数量（0以上。0は計画上の休止） |
| `Note` | | 備考 |

- **製造日＋品目コード＋工程コード＋作業区コードが同じ行は上書き**、無ければ新規登録です。
  計画を改訂したら、同じCSVを直して取り込み直せば反映されます（値が変わらない行は更新されません）。
- CSVに無い計画は消えません。不要な計画は画面から削除してください。
- ファイル内で同じキーが2行ある場合や、作業区の範囲が重なる行（既存の計画との間も含む）はエラーになります。
- 「1行でもエラーがあると全件取り消し」「検証のみ」「UTF-8 / Shift_JIS のどちらでも可」はマスタのCSVと同じです。
- **CSVエクスポートは全件ではなく、一覧の絞り込み欄（製造日の期間・品目・工程・作業区）の条件で出力します**。
  出力したCSVはそのまま直して取り込み直せます。
- 取込の権限は画面から登録するときと同じ（システム管理者・生産管理担当者）です。

<div class="note">
<p>生産計画はマスタではないので、マスタ管理の <strong>ZIPで一括取込・一括出力</strong> には含まれません
（日々増えるデータを、マスタの移行や全件出力に巻き込まないためです）。計画のCSVは必ずこのタブから扱ってください。</p>
</div>

### 予実を見る

**予実** タブでは、製造日×品目×工程ごとに **計画数量・実績数量・達成率** を一覧にします。

| 列 | 内容 |
|---|---|
| 製造日 / 品目 / 工程 | 突き合わせの単位 |
| 計画数量 | その日の計画。同じ製造日・品目・工程に作業区違いの計画があれば合計します |
| 実績数量 | その工程の生産実績の**良品数** |
| 達成率 | 実績数量 ÷ 計画数量 × 100。計画が 0 の日は「-」 |

期間はダッシュボードと同じく **日次・週次・月次** を選び、**◀ 前へ／次へ ▶** で移動します。
品目・工程・作業区で絞り込めます。**品目と工程を1つずつ選ぶと**、日ごとの計画（棒）と実績（折れ線）のグラフが出ます
（品目をまたぐと単位が違い、工程をまたぐと同じ品物を工程の数だけ数えることになるため、絞らないとグラフは出ません）。

- 実績は**開始した製造日**に入ります（ダッシュボードと同じ。夜勤の実績は開始した日の分です）。
- **リワーク指図の産出は数えません**（同じ品物を2度数えないため。生産性の集計と同じ規則です）。
- 計画だけの日（まだ作っていない）も、実績だけの日（計画の無い生産）も1行になり、無い側は 0 です。
- **作業区で絞ると、計画・実績とも作業区が配下にあるものだけ**になります。作業区なしの計画や、
  作業区を持たない工程（外注など）の実績は外れます。実績の作業区は、工程展開したときの工順の作業区です。

<div class="note">
<p>サンプルデータで試すときは、マスタのサンプル（<code>samples-master-csv.zip</code>）と
<a href="masters.html#actual-csv">3か月分の実績</a>（<code>samples-actual-csv-bulk.zip</code>）を取り込んだ後、
<a href="https://github.com/msmsrep/ParallelFactoryMES/releases/latest/download/samples-production-plans.csv">samples-production-plans.csv</a>
を計画登録タブのCSV入出力から取り込みます。予実タブで <strong>月次</strong> を選んで 2026年7〜9月へ戻してください。
工具摩耗が起きた 8/24 の週は加工の達成率が下がり、お盆休み（8/10〜8/14）は計画 0 の日として並びます。</p>
</div>

## 製造指図を登録する

**左メニュー：生産・製造実行 → 製造指図**

登録フォームは **システム管理者・生産管理担当者** にのみ表示されます。

<ol class="steps">
<li><strong>品目</strong>を選びます（製品・半製品のいずれか）。</li>
<li><strong>数量</strong>を入力します。0より大きい値が必要です。</li>
<li><strong>納期</strong>を指定します（任意）。</li>
<li><strong>指図区分</strong>を選びます。通常の生産は「通常」、現場発の割り込みは「突発」です。</li>
<li>必要なら<strong>備考</strong>を入力し、<strong>登録</strong>を押します。</li>
</ol>

登録すると **指図番号が自動採番** され（`MO20260501-0001` の形式）、状態は **未承認（下書き）** になります。

<div class="note">
<p><strong>リワーク指図</strong>は、この画面からは作成しません。
不適合管理で対応区分に「リワーク」を指示すると、リワーク指図が自動的に作成されます
（<a href="quality.html#nc-action">品質管理</a>を参照）。</p>
</div>

### 一覧のしぼり込み

一覧上部のプルダウンで、未承認・承認済・展開済・完了・取消の状態別に絞り込めます。
「産出ロット」列には、工程展開時に採番された製品ロット番号が表示されます。

## 指図詳細と、承認・工程展開

一覧の **詳細** ボタン（または指図番号のリンク）から指図詳細を開きます。

指図の状態によって、表示されるボタンが変わります。

| 状態 | 表示されるボタン |
|---|---|
| 未承認 | 承認 ／ 取消 |
| 承認済 | 工程展開 ／ 取消 |
| 展開済 | 取消 |
| 完了・取消 | なし |

### 承認する

**承認** を押すと状態が「承認済」になります。承認しないと工程展開できません。

### 工程展開する

**工程展開** を押すと、次の処理がまとめて行われます。

- 品目に登録された**工順（BOP）に基づいて、工程ごとの作業指示が自動生成**されます
- **産出ロット番号が自動採番**されます（`品目コード-20260501-001` の形式）
- 指図の状態が「展開済」になります

展開後は画面下部に作業指示の一覧が表示され、各行から次の画面へ進めます。

| ボタン | 移動先 |
|---|---|
| 段取り | 段取り・チェックリスト画面 |
| 実績入力 | 実績入力画面 |
| 指示書 | 作業指示書の印刷ページ（別タブ） |

<div class="warn">
<p>工程展開でエラーになる場合、ほとんどは<strong>工順（BOP）が未登録</strong>です。
マスタ管理 → 品目・MBOM・工順 で対象品目の工順を登録してから、もう一度お試しください。</p>
</div>

### 変更する  {#edit}

未承認・承認済の指図は、**変更** から数量・納期・備考を直せます（システム管理者・生産管理担当者）。

<div class="note">
<p><strong>承認済みの指図を変更すると未承認に戻り、承認をやり直します</strong>
（承認した内容と実際の内容がずれないようにするためです）。
品目は変更できません。品目を間違えた場合は取り消して登録し直してください。</p>
</div>

### 取消する  {#cancel}

**取消** を押すと指図が取消状態になり、紐づく作業指示もあわせて取消されます。
完了・取消済みの指図は取り消せません。

<div class="note">
<p>展開済み以降の指図は、数量・納期などの<strong>変更ができません</strong>（取消のみ可能）。
内容を直したい場合は取り消して登録し直してください。</p>
</div>

## 進捗を確認する

進捗の見かたは4か所あります。

| 画面 | 見えるもの |
|---|---|
| ダッシュボード | 指図ごとの「完了工程数 / 全工程数」と納期超過 |
| 生産計画・予実 | 製造日×品目×工程ごとの計画数量と実績数量・達成率（[上記](#plan)） |
| 製造指図 → 詳細 | その指図の作業指示ごとの状態・担当者・設備 |
| 工程進捗・トラブル | 工程ごとに、未配布／配布済／着手／完了／承認済の件数を集計 |

工程進捗画面については[製造実行](execution.html#progress)を参照してください。
