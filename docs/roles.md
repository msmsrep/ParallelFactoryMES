## ロールの一覧

| ロール | 想定する担当 | 主な権限 |
|---|---|---|
| システム管理者 | 情報システム／導入担当 | すべてのマスタ管理、ユーザー管理。他ロールの操作もすべて実行できます |
| 生産管理担当者 | 生産計画・生産管理 | 製造指図の発行・承認・工程展開・差立、マスタ管理、在庫操作 |
| 現場作業者 | ライン作業者 | 作業指示の確認、段取り・チェックリスト・実績の記録 |
| 物流・倉庫担当者 | 倉庫・出荷 | 受入、在庫操作、出庫・払出、出荷、棚卸 |
| 品質管理担当者 | 品質管理（QC） | 検査の指示・実績・判定・承認、不適合の対応指示・承認 |
| 品質保証担当者 | 品質保証（QA） | 出荷判定と判定承認 |
| 設備保全担当者 | 保全 | 保全計画・手順書の管理、保全指示の取消、治工具メンテナンス |

<div class="note">
<p><strong>システム管理者はすべての操作を実行できます。</strong> 小規模な運用では、
まずシステム管理者1名と、業務ごとのロールを付けたユーザーを数名用意すれば十分です。</p>
</div>

## ロールの割り当て方

**マスタ管理 → ユーザー** タブ（システム管理者専用）で、ユーザーごとにチェックボックスで設定します。
複数のロールを同時に付与できます。

### 割り当ての例

| 担当 | 付与するロール |
|---|---|
| 導入担当者 | システム管理者 |
| 生産計画担当 | 生産管理担当者 |
| ライン作業者 | 現場作業者 |
| 倉庫担当（検査も兼務） | 物流・倉庫担当者 ＋ 品質管理担当者 |
| 品質保証責任者 | 品質保証担当者 |
| 保全担当 | 設備保全担当者 |

## 権限がないときの見えかた

- 登録フォームや承認ボタンが**そのまま表示されません**（グレーアウトではなく非表示）。
- 一覧の閲覧はどのロールでもできます。
- 差立画面で作業者のプルダウンが空になるのは、ユーザー一覧の参照権限（システム管理者）がないためです。
  この場合も設備・着手順の割当は行えます。

「操作したい機能のボタンが見つからない」ときは、まず自分のロールを確認してください。
