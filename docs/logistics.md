在庫を動かす操作（受入以外の在庫操作・ピッキング・出荷・棚卸）は、
**システム管理者・生産管理担当者・物流倉庫担当者** が実行できます。

---

## 受入  {#receiving}

**左メニュー：物流・在庫 → 受入**

購入した部材を在庫に計上します。**製造を始める前に、必要な部材をここで受け入れておきます。**

<ol class="steps">
<li><strong>品目</strong>を選びます。</li>
<li><strong>数量</strong>を入力します。</li>
<li><strong>入庫先ロケーション</strong>を選びます。</li>
<li><strong>ロット番号</strong>を入力します。<strong>空欄にすると自動採番</strong>されます（納入元のロット番号をスキャン入力することもできます）。</li>
<li>必要なら<strong>有効期限</strong>と<strong>備考</strong>を入力します。</li>
<li><strong>受入登録</strong>を押します。</li>
</ol>

登録すると受入ロットが作られ、下の「受入済みロット」一覧に表示されます。

### 現品票の印刷

一覧の **現品票** ボタンで、ロット番号のバーコード（Code39）付きの現品票を印刷できます。

### 受入の取消

**受入取消** を押すと、受入とその在庫計上が取り消されます。

<div class="warn">
<p><strong>受入後に在庫が動いているロットは取り消せません。</strong>
（<code>受入後に在庫が変動しているため取消できません（数量調整で対応してください）。</code>）
この場合は在庫照会・操作の<strong>数量調整</strong>で対応してください。</p>
</div>

## 在庫照会・在庫オペレーション

**左メニュー：物流・在庫 → 在庫照会・操作**

4つのタブで構成されています。

### 在庫照会タブ

ロット番号（スキャン可）とロケーションで在庫を検索します。各行から次の操作ができます。

| ボタン | 動作 |
|---|---|
| 操作 | そのロットを選択した状態で「在庫操作」タブに移動します |
| 現品票 | 現品票を印刷（別タブ） |
| 追跡 | そのロットのトレーサビリティ画面に移動 |

### 在庫操作タブ  {#stock-ops}

<div class="note">
<p>画面の一番上にある<strong>「対象在庫の選択」</strong>で、ロット・対象ロケーション・数量・理由を先に指定してから、
下の各操作ボタンを押します。在庫照会タブの<strong>操作</strong>ボタンから来た場合は、すでに選択済みです。</p>
</div>

| 操作 | 内容 | 使う入力欄 |
|---|---|---|
| 移動 | 別のロケーションへ在庫を移します | 移動先ロケーション、数量 |
| 数量を調整 | 実棚数に合わせて数量を修正します | 実棚数量（調整後の数量）、理由 |
| 分割 | ロットの一部を新しいロットに切り出します | 数量、新ロット番号（空欄で自動採番） |
| 統合 | 対象ロットを統合先ロットにまとめます | 統合先ロット |
| 振替 | 品目やロット番号を変更して在庫を移します | 振替先品目 または 新ロット番号、数量 |
| ステータス変更 | 在庫ステータスを変更します | 在庫ステータス、理由 |
| 廃棄 | 在庫を廃棄します | 数量、理由 |
| 返品 | サプライヤーへ返品して在庫を引き落とします | 数量、理由 |
| 払出戻し | 工程に払い出した部材を在庫に戻します | 数量 |

**在庫ステータス**は、正常／保留／検査待ち／不良／廃棄予定 の5種類です。
検査を発行すると自動で「検査待ち」になり、判定結果に応じて「正常」または「不良」に変わります。

<div class="warn">
<p><strong>数量調整には理由が必須です</strong>（未入力の場合は「実棚差異」として記録されます）。
数量調整・ステータス変更・廃棄は<strong>監査ログに記録されます</strong>。</p>
<p>統合できるのは<strong>同一品目・同一ロケーション</strong>の在庫だけです。</p>
</div>

### 期限アラートタブ

「何日以内の期限を表示するか」に日数を入れると、その期間内に期限が来る在庫と、
すでに期限切れの在庫が一覧されます。期限切れは赤、期限接近は黄色のバッジで区別されます。

### 入出庫履歴タブ

すべての在庫トランザクションが日時順に表示されます。
区分は 受入／入庫／出庫／工程払出／払出戻し／移動／調整／廃棄／返品／振替／分割／統合／棚卸調整／出荷 です。

## 出庫・工程払出  {#picking}

**左メニュー：物流・在庫 → 出庫・払出**

工程へ部材を払い出すとき、または出荷用の製品を用意するときに使います。

### ピッキング指示を作る

<ol class="steps">
<li><strong>区分</strong>を選びます。工程へ払い出すなら「工程払出」、出荷用なら「出荷」です。</li>
<li>区分に応じて<strong>払出先 作業指示</strong>または<strong>払出先 出荷指示</strong>を選びます。</li>
<li><strong>品目</strong>と<strong>数量</strong>を入れて<strong>明細に追加</strong>を押します。複数行を追加できます。</li>
<li><strong>ピッキング指示を作成</strong>を押します。</li>
</ol>

作成時に、**在庫が先入れ先出し（有効期限を優先）で自動的に引き当てられ**、
どのロット・どのロケーションから取るかが決まります。

<div class="warn">
<p>在庫が足りない場合はここでエラーになります。受入や前工程の実績登録で在庫を用意してから、もう一度作成してください。</p>
</div>

### ピッキングを実行する

<ol class="steps">
<li>一覧で対象のピッキング指示を確認します。明細に引当ロットとロケーションが表示されています。</li>
<li>現物のラベルを「照合」欄でスキャンします。引当ロットと一致すれば緑の<strong>一致</strong>、違えば赤の<strong>不一致</strong>が表示されます。</li>
<li>すべて確認できたら<strong>ピッキング実行</strong>を押します。在庫が引き落とされ、状態が「完了」になります。</li>
</ol>

<div class="note">
<p>照合結果は<strong>目視確認のための表示</strong>です。不一致でも実行ボタンは押せてしまうため、
必ず一致を確認してから実行してください。</p>
</div>

間違えて作成した場合は **取消** で取り消せます（指示状態のもののみ）。

## 出荷管理

**左メニュー：物流・在庫 → 出荷管理**

<div class="warn">
<p><strong>出荷を実行するには、その出荷指示に対する「承認済みの出荷判定（可 または 特別採用）」が必要です。</strong>
判定がないと出荷実行時にエラーになります。判定は品質保証担当者が
<a href="assurance.html">出荷判定</a>画面で行います。</p>
</div>

### 出荷指示を作る

<ol class="steps">
<li><strong>出荷先</strong>と<strong>出荷予定日</strong>を入力します。</li>
<li><strong>品目</strong>と<strong>数量</strong>を入れて<strong>明細に追加</strong>を押します。</li>
<li><strong>出荷指示を作成</strong>を押します。出荷番号が自動採番されます。</li>
</ol>

### 出荷を実行する

<ol class="steps">
<li>一覧から対象の出荷指示を開きます。</li>
<li><strong>出荷ロット</strong>を選びます（明細の品目に該当する在庫だけが表示されます）。</li>
<li><strong>数量</strong>を入力します。</li>
<li><strong>出荷実行・完了報告</strong>を押します。</li>
</ol>

実行すると在庫が引き落とされ、明細の「出荷済」数量が増えます。

出荷判定が未承認の場合は次のエラーになります。

> `承認済みの出荷判定（可または特採）がないため出荷できません（H-10-10）。`

### 出荷伝票

各出荷指示の **出荷伝票** ボタンから、伝票を印刷できます。

## 棚卸

**左メニュー：物流・在庫 → 棚卸**

<ol class="steps">
<li><strong>対象ロケーション</strong>を選びます（未選択なら全ロケーション）。</li>
<li><strong>棚卸指示を作成（現在庫をスナップショット）</strong>を押します。この時点の在庫が理論数量として固定されます。</li>
<li>一覧から <strong>開く</strong> を押して明細を表示します。</li>
<li>現物を数え、各行の<strong>実棚数量</strong>を入力します。</li>
<li><strong>実棚数を登録</strong>を押します。差異が計算され、0でない行は赤字で表示されます。</li>
<li>差異を確認したら<strong>確定（差異を棚卸調整）</strong>を押します。差異が在庫に反映され、状態が「確定」になります。</li>
</ol>

**棚卸表** ボタンから、現場で記入するための棚卸表を印刷できます。
中断する場合は **取消** で棚卸自体を取り消せます。

<div class="note">
<p>棚卸指示の作成時に対象在庫が1件もないとエラーになります（<code>対象在庫がありません。</code>）。
ロケーションの指定を見直してください。</p>
</div>
