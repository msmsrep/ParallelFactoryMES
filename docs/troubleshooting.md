## ログイン・アカウント

| 症状・メッセージ | 原因と対処 |
|---|---|
| ユーザー名またはパスワードが正しくありません。 | 入力を確認してください。大文字・小文字は区別されます |
| アカウントが一時的にロックされています。しばらく待って再試行してください。 | ログイン失敗が続いたためのロックです。時間をおいて再試行するか、管理者にパスワードのリセットを依頼してください |
| ログイン画面に「初期セットアップが必要です」と出る | ユーザーが1件も登録されていません。リンクから初期管理者を作成してください |
| ダッシュボードに「初期パスワードのままです」と出る | リンクからパスワードを変更してください。変更するまで表示され続けます |
| セットアップに失敗しました | パスワードが **8文字以上・英小文字と数字を含む** 条件を満たしていません |
| 初期セットアップは完了済みです。 | すでにユーザーが存在します。ログイン画面から通常どおりログインしてください |
| 操作したいボタンが画面に見当たらない | ロールの権限がありません。[ロールと権限](roles.html)を確認し、管理者にロールの付与を依頼してください |

## 製造指図・工程展開

| メッセージ | 対処 |
|---|---|
| 状態 '○○' の指図は展開できません（承認済みの指図のみ）。 | 先に **承認** してください |
| 工程展開でエラーになる／作業指示が生成されない | 品目に**工順（BOP）が未登録**です。[マスタ管理](masters.html#bop)で登録してください |
| 状態 '○○' の指図は変更できません（展開済み以降は取消のみ可能です）。 | 展開後は内容変更できません。取り消して登録し直してください |
| 存在しない（または無効な）品目IDです。 | 品目が無効化されています。マスタ管理で確認してください |
| リワーク指図には元指図ID（sourceOrderId）が必要です。 | リワーク指図は不適合管理の「リワーク」対応指示から作成してください |

## 差立

| メッセージ | 対処 |
|---|---|
| 担当者 '○○' のスキル '△△' は有効期限切れです。 | マスタ管理 → ユーザー → スキル・資格 で有効期限を更新してください（差立・着手・保全実績・検査実績の登録で出ます） |
| 割当作業者が存在しないか無効です。 | ユーザーが無効化されています |
| 状態 '○○' の作業指示は差立できません。 | 着手済み以降の作業指示は差立できません |
| 作業者のプルダウンが「未割当」しか出ない | ユーザー一覧の参照権限（システム管理者）がありません。設備・着手順だけの割当は可能です |

## 実績入力

| メッセージ | 対処 |
|---|---|
| 最終工程の実績には入庫先ロケーション（outputLocationId）が必要です。 | **入庫先ロケーション**を選んでから登録してください |
| MBOMが未登録のためバックフラッシュできません。 | [マスタ管理](masters.html#mbom)でMBOMを登録するか、バックフラッシュのチェックを外してください |
| この工程（工程順序 ○○）で消費する予定材料が無いためバックフラッシュできません。 | この工程で使う部材はありません。バックフラッシュのチェックを外してください。部材を使う工程なら[MBOM](masters.html#mbom)の消費工程を直し、指図を作り直してください |
| MBOMの部材 '○○' の消費工程（工程順序 ○○）が品目 '○○' の工順にありません。 | [MBOM](masters.html#mbom)の消費工程か工順を直してから展開してください |
| 良品数と不良数の合計は0より大きい必要があります。 | どちらかに数量を入力してください |
| 状態 '○○' の作業指示には実績を記録できません。 | すでに承認済み、または取消済みです |
| 状態 '○○' の作業指示は承認できません（完了済みのみ）。 | 実績を登録して「完了」にしてから承認してください |
| バックフラッシュで在庫不足のエラーになる | 受入または前工程の実績登録で部材在庫を用意してください |

## 在庫・受入

| メッセージ | 対処 |
|---|---|
| 受入後に在庫が変動しているため取消できません（数量調整で対応してください）。 | 在庫照会・操作の**数量調整**で修正してください |
| 現在数量と同じため調整は不要です。 | 調整後の数量が現在数量と同じです |
| 品目が異なるロットは統合できません。 | 統合は同一品目・同一ロケーションの在庫だけが対象です |
| 統合元と統合先が同一ロットです。 | 別のロットを統合先に指定してください |
| 統合元の在庫がありません。 | 対象ロットの在庫が0です |
| 新品目ID（品目振替）または新ロット番号（ロット振替）を指定してください。 | 振替先品目か新ロット番号のどちらかを入力してください |
| 対象ロットを選択してください。 | 在庫操作タブの「対象在庫の選択」でロットを選んでから操作してください |

## 出庫・払出／出荷

| メッセージ | 対処 |
|---|---|
| ピッキング指示の作成でエラーになる（在庫不足） | 受入や前工程の実績で在庫を用意してください |
| 工程払出には有効な作業指示ID（workOrderId）が必要です。 | 払出先の作業指示を選択してください |
| 出荷ピッキングには有効な出荷指示ID（shippingOrderId）が必要です。 | 払出先の出荷指示を選択してください |
| 承認済みの出荷判定（可または特採）がないため出荷できません（H-10-10）。 | 品質保証担当者に[出荷判定](assurance.html)の登録と**承認**を依頼してください。「保留」判定では出荷できません |
| 状態 '○○' の出荷指示は実行できません。 | すでに完了または取消済みです |

## 検査・不適合

| メッセージ | 対処 |
|---|---|
| 対象に合致する検査基準がありません。検査項目マスタを登録するか itemIds を指定してください。 | [マスタ管理 → 検査項目・基準](masters.html#inspection-items)に、その検査種別・品目・工程に合致する項目を登録してください |
| 工程内検査には対象作業指示ID（targetWorkOrderId）が必要です。 | 工程内検査では対象作業指示を選んでください |
| 対象ロットID（targetLotId）が必要です。 | 工程内検査以外では対象ロットを指定してください |
| 検査項目 '○○' は規格値による自動判定ができません。judgmentを指定してください。 | その行の「判定（手動）」で合格／不合格を選んでください |
| 実績未登録の検査項目が N 件あります。全項目の実績登録後に判定してください。 | すべての項目に実績を入力してから判定してください |
| 承認済みの検査は訂正できません。 | 承認後の訂正はできません。再検査の検査指示を発行してください |
| 訂正理由を入力してください。 | 検査実績の訂正には理由が必須です |
| クローズ済みの不適合には対応指示できません。 | 新たに不適合を起票してください |
| 対応指示前の不適合は承認できません。 | 先に対応区分を指示してください |

## 設備保全・治工具

| メッセージ | 対処 |
|---|---|
| 停止・故障の記録には停止原因（stopCause）が必要です（B-40-20-02）。 | 停止原因を入力してください |
| 対象設備IDまたは対象治工具IDのどちらか一方を指定してください。 | 設備か治工具のどちらか一方だけを選んでください |
| 使用回数または使用時間のどちらかを記録してください。 | 治工具の利用実績には、回数か時間のいずれかが必要です |
| 稼働サマリに数値が出ない | **終了時刻まで記録された**稼働実績だけが集計対象です |
| 状態 '○○' の保全計画からは指示を作成できません。 | 「計画」状態の計画からのみ指示を発行できます |

## スキャン・印刷

| 症状 | 対処 |
|---|---|
| カメラを利用できません（未対応ブラウザ／権限拒否）。 | HTTPS接続が必要です（`localhost` は例外）。USBバーコードリーダーまたは手入力をご利用ください |
| カメラの権限を一度拒否してしまった | ブラウザのアドレスバーのアイコンから、カメラの権限を「許可」に変更してください |
| 帳票の画面が開かない | ポップアップブロックの可能性があります。ブラウザの設定でこのサイトのポップアップを許可してください |
| PDFで保存したい | 印刷ダイアログでプリンタに「PDFとして保存」を選んでください |

## 導入・起動  {#install}

| 症状 | 対処 |
|---|---|
| ZIP版の起動で「WindowsによってPCが保護されました」と出る | インターネットから入手したファイルに付く警告です。**詳細情報 → 実行** で起動できます。毎回出さないようにするには、展開する前にZIPファイルのプロパティで **許可する** にチェックを入れ、展開し直してください |
| Linux で `./start.sh` が「許可がありません（Permission denied）」になる | ZIPは実行権限を保持しません。`sh start.sh` で起動してください（起動時に本体へ実行権限を付けます） |
| ZIP版を起動するとすぐ閉じる／ポートが使用中と出る | 別のアプリがポート 5000 を使っています。`MESAPP_URLS` でポートを変えてから起動してください（例：`set MESAPP_URLS=http://0.0.0.0:5100`） |
| Docker でコンテナを作り直したらデータが消えた | `/data` をボリュームにしていません。`-v mesapp-data:/data` を付けて起動してください（[管理者向け運用](operations.html#docker)） |
| Store版で初期パスワードがわからない | 初期パスワードは、変更するまで画面の上に表示され続けます。表示が消えている場合は変更済みです。忘れた場合は下の「ログイン・アカウント」を参照してください |

## 表示・接続

| 症状 | 対処 |
|---|---|
| 画面が「読み込み中...」のまま | サーバーが停止しているか、ネットワークが切断されています。管理者に確認してください |
| 操作していると突然ログイン画面に戻る | アクセストークンの有効期限切れです。再ログインしてください。有効期限は設定で変更できます |
| 他のPCから接続できない | サーバー側のファイアウォールでポートの受信許可が必要です（[管理者向け運用](operations.html)） |

## それでも解決しないとき

管理者に連絡する際は、次の情報を伝えるとスムーズです。

- 操作していた画面と、押したボタン
- 画面に表示された**エラー文言をそのまま**
- 対象の番号（指図番号・作業指示番号・ロット番号など）
- 操作した日時とログインユーザー名
