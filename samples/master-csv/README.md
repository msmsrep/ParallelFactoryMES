# サンプルマスタCSV

マスタ管理の [CSV入出力](https://msmsrep.github.io/ParallelFactoryMES/masters.html#csv) で、そのまま取り込める
サンプルデータです。**どんな内容をどの列に入れるか**の参考にしてください。

想定しているのは、鋳造品を機械加工・表面処理してハウジングを作り、購入部材と組み立てて
**ギアポンプ（FG-1000）を生産する小規模な工場**です。取り込むと、製造指図の登録から
工程展開・実績入力・検査・出荷まで一通り試せる状態になります。

```
RM-3001 ハウジング鋳造品
   └─(PR-10 機械加工 → PR-20 表面処理[外注])→ SF-2000 ハウジング加工品
                                                    │
   RM-3002 ギアセット / RM-3003 シャフト / RM-3004 Oリング（代替 RM-3007） /
   RM-3005 六角ボルト / RM-3006 潤滑油 ────────────┤
                                                    ↓
                          (PR-30 組立 → PR-40 最終検査 → PR-50 梱包) → FG-1000 ギアポンプ組立品
```

## 取り込む順番

**ファイル名の番号順**に取り込んでください。後のファイルが前のファイルのコードを参照するため、
順番を飛ばすと「登録されていません」というエラーになります。

| # | ファイル | タブ | 内容 |
|---|---|---|---|
| 01 | `01_work-centers.csv` | 作業区 | 工場 → ライン → エリア → 作業区の4段 |
| 02 | `02_processes.csv` | 工程 | 機械加工・表面処理（外注）・組立・最終検査・梱包 |
| 03 | `03_locations.csv` | ロケーション | 部材倉庫・保全部品棚・工程内・製品倉庫・出荷場（所属する作業区つき） |
| 04 | `04_products.csv` | 品目・MBOM・工順 | 製品1・半製品1・部材7・保全部品3（既定ロケーションつき） |
| 05 | `05_skills.csv` | スキル・資格 | 有効期限ありの資格を含む（システム管理者のみ取込可） |
| 06 | `06_shifts.csv` | 勤務シフト | 昼勤と、日をまたぐ夜勤（システム管理者のみ取込可） |
| 07 | `07_equipments.csv` | 設備（BOE） | 保全タイプ（回数／カレンダ／稼働時間）の書き分け。設置場所は作業区 |
| 08 | `08_equipment-parts.csv` | 設備（BOE） | 保全部品（資産管理部品／消耗品） |
| 09 | `09_tools.csv` | 治工具 | 寿命閾値（回数／時間）の書き分け |
| 10 | `10_checklists.csv` | チェックリスト | 同じコードの複数行が1つのチェックリストになる例 |
| 11 | `11_defect-reasons.csv` | 不良理由 | 材質・加工・設備・人的要因・その他 |
| 12 | `12_inspection-items.csv` | 検査項目・基準 | 規格値あり／なし、受入・工程内・完成品・サンプル検査 |
| 13 | `13_control-items.csv` | 工程管理項目 | 指示値と許容範囲（製造条件の逸脱判定に使う）。どの工程で記録するかは `17_routing.csv` の `ControlItemCodes` で紐付ける |
| 14 | `14_inspection-devices.csv` | 検査機・測定器 | 校正期限切れの機器を1台含む（システム管理者のみ取込可） |
| 15 | `15_bom.csv` | 品目・MBOM・工順 | FG-1000 と SF-2000 のMBOM。Oリングに代替部品あり。部材はどれも最初の工程（工程10）で消費する |
| 16 | `16_work-procedures.csv` | 作業手順書 | 手順を本文に書く例と、所在だけを書く例（システム管理者のみ取込可） |
| 17 | `17_routing.csv` | 品目・MBOM・工順 | 候補設備・作業区・治工具・スキル・チェックリスト・工程管理項目・手順書を紐づけた工順 |
| 18 | `18_users.csv` | ユーザー | 各ロールの担当者。作業場所・所属・直つき（システム管理者のみ取込可） |
| 19 | `19_user-skills.csv` | ユーザー | ユーザーへのスキル・資格の割当（システム管理者のみ取込可） |

取り込み方は、マスタ管理の各タブで **CSV入出力 → 取込ファイルを選択 → 取込を実行** です。
このフォルダのCSVをまとめてZIPにすれば、画面上部の **ZIPで一括取込** から1回で取り込めます（ファイル名の順。1ファイルでもエラーがあればZIPの全ファイルを取り消し）。

初めての場合は **検証のみ** にチェックを入れて実行し、エラーが出ないことを確認してから
チェックを外して取り込むと安全です。

## このサンプルで確認できる書き方

- **カンマや改行を含む値**は `"..."` で囲む（`04_products.csv` の規格、`16_work-procedures.csv` の手順ステップ）
- **空欄**にすると、その項目は未設定になる（`03_locations.csv` の棚番など）
- **列そのものを省く**と現在の値が保たれる（`12_inspection-items.csv` は出力専用の `Version` 列、
  `07_equipments.csv` は旧項目の `Site`・`MaintenanceParts` 列を省略）
- **明細は同じキーの行をまとめる**（`08_equipment-parts.csv` は設備単位、`10_checklists.csv` はコード単位、
  `15_bom.csv` は親品目単位、`17_routing.csv` は品目単位。取込時はその明細を丸ごと置き換えます）
- **他のマスタはコードで参照する**（`17_routing.csv` の `ProcessCode` / `EquipmentAssetNo` など）
- **複数の値はセミコロンで区切る**（`17_routing.csv` の `EquipmentAssetNos`・`ControlItemCodes`、`18_users.csv` の `Roles`）
- **設備と工順の作業区は最下段（作業区）だけ**を指定できる。ロケーションとユーザーは工場・エリアなど、どの段でもよい
- **工程順序は 10, 20, 30 のように間隔を空けておく**と、後から工程を差し込みやすくなります

## 試せる業務のポイント

- `RM-3007`（耐油Oリング）は `RM-3004` の代替部品です。投入するときは理由の入力が求められます
- `FG-1000` の標準不良率は 1.5%、`SF-2000` は 2% です。製造指図を展開すると、予定材料がこの率ぶん割り増されます
  （例：ギアポンプ10台の指図で、ギアセットの予定数量は 10 ÷ (1 − 0.015) ＝ 10.152285）
- `14_inspection-devices.csv` の `DV-03` は校正期限切れです。検査実績の測定器に選ぶと登録できません
- `SF-2000` の機械加工は `EQ-01` と `EQ-05` のどちらでも作業できます（候補設備）
- `op003` は夜勤（20:00〜翌05:00）の作業者です。直別の集計を試せます

## 注意

- `18_users.csv` の `InitialPassword` は**サンプル用の仮パスワード**です。実際に運用するときは
  必ず別の値に変更してください（取り込んだユーザーは初回ログイン時にパスワード変更を求められます）。
  取り込んだ後のCSVファイルは削除するなど、取り扱いに注意してください。
- 文字コードは **UTF-8（BOM付き）** です。Excelでそのまま開けます。
  Shift_JISで保存し直しても取り込めます。
- サンプルを取り込んだ後の在庫はゼロです。**受入**で部材在庫を計上してから製造指図を進めてください。
