# サンプルマスタCSV

マスタ管理の [CSV入出力](https://msmsrep.github.io/ParallelFactoryMES/masters.html#csv) で、そのまま取り込める
サンプルデータです。**どんな内容をどの列に入れるか**の参考にしてください。

想定しているのは、鋳造品を機械加工・表面処理してハウジングを作り、購入部材と組み立てて
**ギアポンプ（FG-1000）を生産する小規模な工場**です。取り込むと、製造指図の登録から
工程展開・実績入力・検査・出荷まで一通り試せる状態になります。

```
RM-3001 ハウジング鋳造品
   └─(PR-10 機械加工 → PR-20 表面処理[外注])→ SF-2000 ハウジング加工品
                                                    │
   RM-3002 ギアセット / RM-3003 シャフト / RM-3004 Oリング /
   RM-3005 六角ボルト / RM-3006 潤滑油 ────────────┤
                                                    ↓
                          (PR-30 組立 → PR-40 最終検査 → PR-50 梱包) → FG-1000 ギアポンプ組立品
```

## 取り込む順番

**ファイル名の番号順**に取り込んでください。後のファイルが前のファイルのコードを参照するため、
順番を飛ばすと「登録されていません」というエラーになります。

| # | ファイル | タブ | 内容 |
|---|---|---|---|
| 01 | `01_processes.csv` | 工程 | 機械加工・表面処理（外注）・組立・最終検査・梱包 |
| 02 | `02_products.csv` | 品目・MBOM・工順 | 製品1・半製品1・部材6 |
| 03 | `03_locations.csv` | ロケーション | 部材倉庫・工程内・製品倉庫・出荷場 |
| 04 | `04_skills.csv` | スキル・資格 | 有効期限ありの資格を含む |
| 05 | `05_equipments.csv` | 設備（BOE） | 保全タイプ（回数／カレンダ／稼働時間）の書き分け |
| 06 | `06_tools.csv` | 治工具 | 寿命閾値（回数／時間）の書き分け |
| 07 | `07_checklists.csv` | チェックリスト | 同じコードの複数行が1つのチェックリストになる例 |
| 08 | `08_inspection-items.csv` | 検査項目・基準 | 規格値あり／なし、受入・工程内・完成品検査 |
| 09 | `09_bom.csv` | 品目・MBOM・工順 | FG-1000 と SF-2000 のMBOM |
| 10 | `10_routing.csv` | 品目・MBOM・工順 | 設備・治工具・スキル・チェックリストを紐づけた工順 |
| 11 | `11_users.csv` | ユーザー | 各ロールの担当者（システム管理者のみ取込可） |
| 12 | `12_user-skills.csv` | ユーザー | ユーザーへのスキル・資格の割当 |

取り込み方は、マスタ管理の各タブで **CSV入出力 → 取込ファイルを選択 → 取込を実行** です。
初めての場合は **検証のみ** にチェックを入れて実行し、エラーが出ないことを確認してから
チェックを外して取り込むと安全です。

## このサンプルで確認できる書き方

- **カンマを含む値**は `"..."` で囲む（`02_products.csv` の規格、`05_equipments.csv` の保全部品）
- **空欄**にすると、その項目は未設定になる（`03_locations.csv` の棚番など）
- **列そのものを省く**と現在の値が保たれる（`08_inspection-items.csv` は出力専用の `Version` 列を省略）
- **明細は同じキーの行をまとめる**（`07_checklists.csv` はコード単位、`09_bom.csv` は親品目単位、
  `10_routing.csv` は品目単位。取込時はその明細を丸ごと置き換えます）
- **他のマスタはコードで参照する**（`10_routing.csv` の `ProcessCode` / `EquipmentAssetNo` など）
- **工程順序は 10, 20, 30 のように間隔を空けておく**と、後から工程を差し込みやすくなります

## 注意

- `11_users.csv` の `InitialPassword` は**サンプル用の仮パスワード**です。実際に運用するときは
  必ず別の値に変更してください（取り込んだユーザーは初回ログイン時にパスワード変更を求められます）。
  取り込んだ後のCSVファイルは削除するなど、取り扱いに注意してください。
- 文字コードは **UTF-8（BOM付き）** です。Excelでそのまま開けます。
  Shift_JISで保存し直しても取り込めます。
- サンプルを取り込んだ後の在庫はゼロです。**受入**で部材在庫を計上してから製造指図を進めてください。
