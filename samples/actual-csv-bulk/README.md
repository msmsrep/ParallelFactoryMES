# サンプル実績CSV（3か月分・ダッシュボード確認用）

[`samples/master-csv/`](../master-csv/) のマスタを取り込んだ後に取り込むと、
ダッシュボードの**推移（日次・週次・月次）**と**内訳（工程・品目・直・ライン・作業区・設備）**を見比べられる量の実績が入ります。
[`samples/actual-csv/`](../actual-csv/)（機能を一通り試すための少量の実績）とは独立しているので、どちらを先に取り込んでも構いません。

| # | ファイル | 種別 | 内容 |
|---|---|---|---|
| 01 | `01_manufacturing-orders.csv` | 製造指図 | 週ごとの指図（ハウジング加工 SF-2000・ギアポンプ FG-1000）。登録→承認→工程展開まで進める |
| 02 | `02_production-records.csv` | 生産実績 | 加工は昼勤・夜勤、組立→最終検査→梱包は昼勤。不良は不良理由別の内訳つき |
| 03 | `03_equipment-logs.csv` | 設備稼働記録 | EQ-01〜05 の稼働・段取り・待機・停止・故障。稼働区間は作業指示に紐づけている |

## 期間と見どころ

期間は **2026-06-29（月）〜 2026-09-20（日）の12週**です。7月・8月は丸1か月ぶん入っています。
ダッシュボードは「今日」を基準に開くので、**基準日を 2026-09-20 などに変えるか「◀ 前へ」で戻して**見てください。

- **不良率は7月→8月→9月と下がる**（月次で比べる）。夜勤は昼勤より高い（内訳の直別で比べる）
- **8/10〜8/14 はお盆休み**で実績なし（週次・日次の谷）
- **8/24 の週はマシニングセンタ EQ-01 の工具摩耗**で故障停止が入り、工具摩耗（DR-04）の不良が増える
- **2号機 EQ-05 は待機が多く稼働率が低い**。9月は段取り改善で待機が減る（設備別の内訳）
- 7月の隔週土曜（7/4・7/18）は加工だけ休日出勤
- 外注の表面処理（SF-2000 工程20）は作業区を持たないので、作業区別・ライン別では「（作業区なし）」に入る

部材の受入・投入は含めません（バックフラッシュしない）。在庫の動きを見るときは `samples/actual-csv/` を使ってください。

## 取り込み方

**管理 → 実績CSV取込** の **ZIPで一括取込** に、このフォルダのCSVをまとめたZIP（リリースの `samples-actual-csv-bulk.zip`）を渡します。
行数が多いので取込には少し時間がかかります。**2回取り込むと指図番号の重複で止まります**（全件取り消されるので中途半端には残りません）。

## 作り直し方

内容は [`scripts/New-SampleBulkActuals.ps1`](../../scripts/New-SampleBulkActuals.ps1) が生成しています（乱数の種を固定しているので、何度作っても同じ内容になります）。
手で編集せず、スクリプトを直して作り直してください。

```powershell
./scripts/New-SampleBulkActuals.ps1
```
