# サンプル生産計画CSV

**生産・製造実行 → 生産計画・予実** の計画登録タブで、**CSV入出力 → 取込ファイルを選択 → 取込を実行** に
そのまま渡せる生産計画です（[ユーザーガイド](https://msmsrep.github.io/ParallelFactoryMES/production.html#plan)）。
生産計画はマスタでも実績でもないので、マスタ・実績のサンプルZIPとは別にしています。

[`samples/master-csv/`](../master-csv/) のマスタを取り込んだ後に取り込んでください（品目・工程・作業区のコードを参照します）。
[`samples/actual-csv-bulk/`](../actual-csv-bulk/)（3か月分の実績）と同じ期間なので、両方を取り込むと予実タブで達成率を見られます。

## 中身

期間は **2026-06-29（月）〜 2026-09-20（日）** の日別の計画（製造日×品目×工程）です。作業区は工順と同じ最下段を指定しています。

| 品目 | 工程 | 作業区 | 計画数量 |
|---|---|---|---|
| SF-2000 ハウジング加工品 | PR-10 機械加工 | WC-MC1 | 平日 76（昼勤40＋夜勤36）。休日出勤の 7/4・7/18 は 40 |
| SF-2000 ハウジング加工品 | PR-20 表面処理（外注） | （空欄） | 週の最終稼働日に1週間ぶん |
| FG-1000 ギアポンプ組立品 | PR-30 組立 / PR-40 最終検査 / PR-50 梱包 | WC-AS1 / WC-QC1 / WC-PK1 | 平日 30 |

## 見どころ

予実タブで集計単位を **月次** にし、**◀ 前へ** で 2026年7〜9月へ戻して見てください。品目と工程を1つずつ選ぶとグラフも出ます。

- 計画は実績とほぼ釣り合う一定の数量なので、達成率はおおむね100%前後になる
- **8/24 の週**は工具摩耗の不良で、加工（PR-10）の達成率が下がる
- **お盆休み（8/10〜8/14）** は計画数量0（計画上の休止）の行として並び、達成率は「-」
- 外注の表面処理（PR-20）は作業区が空欄。作業区で絞ると計画・実績とも外れる

## 取込のきまり（このサンプルで確認できること）

- **製造日＋品目コード＋工程コード＋作業区コードが同じ行は上書き**、無ければ新規登録。同じファイルを取り込み直しても増えない
- **作業区の空欄も1つのキー**（PR-20 の行）
- 計画数量 **0 は計画上の休止**

## 作り直し方

[`scripts/New-SampleBulkActuals.ps1`](../../scripts/New-SampleBulkActuals.ps1) が3か月分の実績と一緒に作っています（計画には乱数を使いません）。
手で編集せず、スクリプトを直して作り直してください。
