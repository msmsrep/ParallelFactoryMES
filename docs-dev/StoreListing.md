**書くときの約束**

- **Store 版でできないことを書かない**。Store 版は1台のPC内で完結し、LAN上の他端末からは接続できない（Spec.md 7.8）。
  「全端末から」「タブレットから」などサーバー配置を前提とした言い回しは紹介ページから流用しない

## 説明（10,000文字以内）

```
Parallel Factory MES は、製造指図・作業実績・在庫・品質・設備保全を1つの流れとして記録する、製造実行システム（MES）です。サーバーやクラウドの準備は要りません。インストールすれば、このPC1台で工場の記録を始められます。

■ こんな現場に
・紙やExcelで管理している製造記録を、ロット単位で追えるようにしたい
・専用サーバーを立てるほどの規模ではないが、指図から出荷までを一貫して残したい
・本格導入の前に、MESの業務の流れを実際に動かして確かめたい

■ 主な機能
【生産管理】製造指図の登録・承認と工程展開、進捗の確認、作業の差立
【製造実行】段取り・チェックリスト、実績入力（良品数・不良数・作業時間）、部材のバックフラッシュ、トラブル報告
【物流・在庫】受入、ロット×ロケーション単位の在庫、出庫・払出・移動・調整、出荷、棚卸
【品質管理】検査指示と検査実績、規格値による合否の自動判定、不適合の記録、品質分析
【品質保証】出荷判定、部材ロットと製品ロットの双方向トレーサビリティ
【設備保全】稼働記録、保全計画・指示・実績、作業手順書、治工具の寿命管理
【帳票】作業指示書・現品票の印刷とPDF出力（バーコード入り）。USBバーコードリーダーでの読み取りに対応
【マスタ・データ連携】品目・工程・工順・設備などのマスタをCSVで一括登録・出力（UTF-8／Shift_JIS）
【管理】ユーザーとロール（権限）、操作の監査ログ

■ 記録を後から追える
製造指図・作業指示・ロットの状態変化は履歴として残り、誰が・いつ・何を変えたかは監査ログで確認できます。訂正した記録も、訂正前の内容と理由が残ります。

■ データはこのPCの中だけに
入力したデータはすべてこのPC内に保存され、開発者を含む第三者には送信されません。利用状況の収集や広告もありません。アプリの画面はPC内部でのみ動作し、ネットワーク上の他の機器からは接続できません。

■ はじめかた
初回起動時にシステム管理者のアカウントが自動で作られ、ユーザー名とパスワードがウィンドウ上端に表示されます。ログインしてパスワードを変更したら、マスタ管理から工程・品目・工順を登録してください。操作手順はユーザーガイド（Webサイト）で画面写真付きで説明しています。

■ ご注意
・1台のPCで使うためのアプリです。複数のPCから同じデータを共有したい場合は、サーバーに配置する形態（ソースコードを公開しています）をご検討ください。
・アンインストールすると、保存したデータもすべて削除されます。必要なデータは、アプリを閉じた状態でデータフォルダーをコピーして事前に保存してください（手順はユーザーガイドの「管理者向け運用」にあります）。
・画面表示に Microsoft Edge WebView2 ランタイムを使用します（Windows 11 には標準で搭載されています）。

本アプリはオープンソースソフトウェア（GNU Affero General Public License v3.0）です。
```
